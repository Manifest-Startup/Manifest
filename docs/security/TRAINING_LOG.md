# Workforce Training Log

Owner: People Ops + Security. Reviewed annually.

This log records completion of mandatory training for everyone with
access to Manifest production systems or PHI under a BAA.

## Required courses

| Course | Cadence | Owner |
|---|---|---|
| Security Awareness 101 | On hire + annual | Security |
| Privacy & GDPR Basics | On hire + annual | DPO |
| HIPAA for Workforce (when in BAA scope) | On hire + annual | DPO |
| Secure Coding (engineers) | Annual | Security |
| Incident Response Tabletop | Annual | Security |

## Completion register

> The active register is maintained in the People Ops HRIS as the
> system of record. This file is the audit-facing evidence stub —
> populate the table below from the HRIS export at each quarterly
> compliance review.

| Person (initials) | Role | Course | Completed (YYYY-MM-DD) | Next due |
|---|---|---|---|---|
| _example_ | Eng | Secure Coding | 2026-01-15 | 2027-01-15 |

## Onboarding gate

A new hire cannot be granted access to production systems until
Security Awareness 101 + Privacy Basics are complete. The access-grant
runbook (`docs/security/ACCESS_REVIEW.md`) checks this register before
provisioning.
