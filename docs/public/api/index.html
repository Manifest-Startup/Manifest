Manifest API

Last verified against code on May 1, 2026.

API Surfaces

  • /graphql: Primary application API (session/JWT auth) — includes ideas, messaging, pitch reels (pitchReelsFeed includes ideaId for linked ideas, togglePublishIdea), social graph, and try-before-signup flows (startGuestSession, mergeGuestWorkspace, profile.isGuest)
  • /api/v1/*: Public REST API (API key auth)
  • /api/keys/*: API key management (session/JWT auth)
  • /api/voice-agent/*: Voice assistant REST API (session/JWT auth)
  • /api/internal/survey-ops/*: Internal survey analytics and GitHub triage loop for trusted agents
  • /api/internal/production-signals/*: Deduped production anomaly ingest; optional GitHub issues (see docs/PRODUCTION_SIGNALS_OPS.md)

Pitch reel video after publish: GOOGLE_API_KEY (Gemini/Veo), optional PITCH_REEL_VIDEO_MODE=disabled on serverless, and production DB migrations for pitch_reels — see API.md (production checklist).

Authentication

Session/JWT

Used by GraphQL and most app REST routes:

Authorization: Bearer <jwt>

Cookies access_token and session_token are also accepted.

API Key

Used by /api/v1/*:

Authorization: Bearer manifest_sk_xxx

Common Endpoints

  • POST /graphql
  • query surveyInsights(windowDays) — aggregate discovery + product feedback (roles, value props, goals, satisfaction/ease, themes)
  • GET /api/v1/ideas
  • POST /api/v1/ideas
  • GET /api/voice-agent/capabilities
  • POST /api/voice-agent/start
  • POST /api/voice-agent/process
  • POST /api/internal/survey-ops/summary (trusted internal loop)
  • POST /api/internal/production-signals/event (trusted internal loop)
