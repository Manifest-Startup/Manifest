# Manifest Dev Tools

Small VS Code and Cursor commands for working on the Manifest repository.

## Commands

- `Manifest: Open MCP Setup` opens `mcp_server/README.md`
- `Manifest: Start Backend` launches the FastAPI app from `backend/`
- `Manifest: Start Frontend` runs `npm start` from `frontend/`
- `Manifest: Start Full Stack` delegates to `manifest-dev start`

This extension is intended for contributors working inside the Manifest repository.
